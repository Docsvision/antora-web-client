= Справочник номенклатуры дел

ЭУ `_Справочник номенклатуры дел_` предназначен для работы администраторов. Справочник открывает возможности создания иерархической структуры разделов для xref:archivemgmt:user:cases.adoc#createCase[создания] дел и списания при помощи ЭУ "xref:5.5.17@archivemgmt:layouts:guide-add-case-control.adoc[Дело]" (только для 5.5.1) или ЭУ "xref:layouts:ctrl/table/dataGridControl.adoc[]" (для 5.5.2 и выше) документов в дело, просмотра документов, списанных в дело, см. подробнее "xref:archivemgmt:layouts:ctrl/nomenclatureOfCases/nomenclatureDirectory.adoc[]".
