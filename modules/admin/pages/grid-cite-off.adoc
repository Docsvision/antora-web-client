= Отключение цитат в режиме ленты

В исключительных случаях большое количество файлов с цитатами может вызывать ошибки при поиске. Когда использование цитат отключено, поиск в режиме ленты будет работать аналогично режиму грида (без цитат).

.Чтобы отключить использование цитат:
. Задайте настройку в БД при помощи скрипта. Значение `0` (MSSQL) или `false` (PGSQL) -- настройка отключена, цитаты отображаются (значение по умолчанию); `1` (MSSQL) или `true` (PGSQL) -- настройка включена, цитаты не отображаются:
+
.Для {mssql}:
[source,sql]
----
DECLARE @On bit =1
EXEC dvsys_setting_set N'DisableSearchCitations', @On
----
+
.Для {pgsql}:
[source,pgsql]
----
select * from dvsys_setting_set('DisableSearchCitations', true);
----
+
. Перезапустите *{sss-new}*.
. Если снова необходимо включить цитаты, в БД выполните скрипт:
+
.Для {mssql}:
[source,sql]
----
DECLARE @On bit =0
EXEC dvsys_setting_set N'DisableSearchCitations', @On
----
+
.Для {pgsql}:
[source,pgsql]
----
select * from dvsys_setting_set('DisableSearchCitations', false);
----
+
. Снова перезапустите *{sss-new}*.
