= Локализация параметров поисковых запросов

В {wc}е названия параметров атрибутивных поисковых запросов будут отображаться на языке пользователя, если выполнена соответствующая настройка.

В {wincl}е локализованные названия будут отображаться по-прежнему даже после выполненных настроек.

Настройка локализации выполняется после установки флага `*Редактировать XML запрос*`, в menu:РМА[раздел "xref:winclient:user:rma/search-advanced.adoc[Расширенный поиск]" > вкладка "XML"].

[IMPORTANT]
====
Пока ручное редактирование XML запроса активно, запрос не может быть изменён на вкладке _Атрибутивный_.
====

.Чтобы настроить локализацию параметров поисковых запросов:
. Откройте РМА, нажмите кнопку image:winclient:user:buttons/magn-glass.png[Лупа] и перейдите на вкладку _XML_, чтобы отредактировать XML запроса.
. Задайте локализованные названия для каждого из желаемых языков.
+
.Пример фрагмента XML:
[source,xml]
----
   <Param Alias="paramalias16" Name="Дата регистрации с" Type="datetime"
          Flags="1" Value="" ContextWord="Today">
     <LocalizedName>
       <LocalizedString Language="ru">Дата регистрации с</LocalizedString> <.>
       <LocalizedString Language="en">Registration date from</LocalizedString> <.>
     </LocalizedName>
   </Param>
----
<.> Локализованное значение параметра "Дата регистрации с" для русского языка.
<.> Локализованное значение параметра "Дата регистрации с" для английского языка.
+
.Правила указания локализованных значений:
* Не меняйте значения `ParameterName` или `Name`, указывайте локализованное значение и код языка (например, `ru`, `en`) в элементе `Language`.
* Указывайте только одно значение для одной локали.
* Пустые значения не используются системой.
