= Журнал аудита безопасности

В журнал событий безопасности записываются события безопасности:

* вход в {wc},
* выход из {wc}а,
* результат попытки входа: успешная или неуспешная,
* превышение лимита неудачных попыток входа,
* дата и время входа,
* идентификатор пользователя, предъявленный при запросе доступа,
* идентификатор (адрес) узла, с которого осуществлялся вход в подсистему.

Журнал записывается в таблицу `dvsys_log_security` в БД {dv}.
