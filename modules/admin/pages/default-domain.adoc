= Настройка автоматической подстановки домена при входе

// tag::webconfig[]
Настройка даёт пользователям возможность не вводить домен при входе. Чтобы активировать настройку, администратор должен внести изменения в конфигурацию {wc}а:

. Откройте конфигурационный файл `{webconfig-win}`.
. Перейдите к элементу menu:configuration[{dv} > WebClient > Authentication].
. Введите название локального компьютера в значение параметра `DefaultDomain`.
. Сохраните изменения конфигурационного файла.
// end::webconfig[]
